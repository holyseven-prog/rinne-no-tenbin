# 輪廻の天秤 / 輪迴之天秤 (Rinne no Tenbin)

Single-file HTML god-sim prototype (ja / zh-TW). Open `index.html` in a browser.

- `src/` — source parts; `node build.js` concatenates them into `index.html` and `test/sim_bundle.js`
- `test/` — headless sim / balance / language / UI tests (`npm i` inside `test/` for puppeteer-core)
- All graphics, music and sound effects are generated by code; no external assets or network requests.
