## 0. 共通規格

| 項目 | 規格 |
| --- | --- |
| 格子大小 | **維持 `TS = 16`**。設計圖寫「1 格 32×32px」，但同一張圖也註明「尺寸、色數請配合專案調整」。人物是 16×24，若格子改成 32，整個遊戲都要重做，所以不改 |
| 建築佔幾格 | **照設計圖的格數**（例：教會 7×6 格＝112×96px） |
| 細節 | 解析度只有設計圖的一半，細節可以**等比簡化**。但下列項目**必須保留**：外形輪廓、屋頂顏色、牆的木框（半木造）樣式、門窗位置、招牌圖示、煙囪、尖塔、十字架 |

| 季節 | 用現有的 `seasonOf()`（每 3 天換一季，春夏秋冬）切換草地、花、田、樹的外觀 |

## 2. 地面（8 種）

看 `03_ground.png`。

| 設計圖 | Tile | 要點 |
| --- | --- | --- |
| 草地 | `GRASS` | 鮮綠；**5 階明暗以群聚方式分布**；每格可做左右翻轉來增加變化 |
| 花地 | `FLOWER` | 草地上點綴白、粉、黃色小花；佔草地的 **約 7%**，隨機出現 |
| 道路（土） | `PATH` | 橘棕色土路，有細碎顆粒 |
| 廣場石板 | `PLAZA` | 灰色石板，石塊錯開排列 |
| 田地（四季） | `FIELD` | **春**：有粉花的作物；**夏**：濃綠作物；**秋**：黃綠熟成作物；**冬**：被雪蓋住 |

## 6. 擺放規則（設計圖註明，照做）

看 `07_rules.png`。
1. 村莊內每 **8×8 格**至少要有 **4 個**物件或樹。
2. 地面 tile 隨機自然配置；**每一格都要有變化**（不可整片一模一樣）。
3. 草地用 **5 階明暗**群聚分布，並加上左右翻轉。
4. 花地約佔草地的 **7%**，隨機出現。
5. 依季節切換草地、花、田、樹的外觀。
6. 橋由程式畫，素材不包含。

- 請寫 `test/props_density.js` 檢查第 1 條：輸出每個 8×8 區塊的物件數，有不足 4 的就列出。
- 建築、路、水面所在的區塊可以除外。
