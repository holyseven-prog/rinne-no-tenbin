## ⚠️ 開工前必做：先打開每一張圖

**這份文件的規格以「圖」為準，文字只是輔助。** 文字和圖不一致時，**以圖為準**。

1. 動手前，用圖片檢視工具（image viewer／Read 圖片）**逐張打開**下表的 PNG，親眼看過再畫。**不可只讀文字就實作。**

## 共通規格（4 張圖都適用）

| 項目 | 規格 |
| --- | --- |
| 格子 | **維持 `TS = 16`**。設計圖寫「1 格 32px」，但每張圖都註明「尺寸、色數請配合專案調整」。人物是 16×24，若格子改 32，整個遊戲要重做 |
| 換算 | 設計圖的「格數」照用（例：教會 7×6 格＝112×96px）。設計圖寫的像素尺寸**除以 2** |
| 細節 | 解析度只有設計圖的一半，細節可以**等比簡化**。但這些**必須保留**：外形輪廓、配色、圖示、紋章、持物、比例 |
| 色數 | 每個素材約 16 色（最多 32 色）；色相以設計圖下方的色票為準 |
| 外框 | 深色外框（`#181020` 系） |
| 季節 | 用現有的 `seasonOf()`（每 3 天一季，春夏秋冬）切換外觀 |
| 參考範圍 | **只照這 4 張設計圖**，不可另外參考或複製 DQ、FF 的實際遊戲素材 |
