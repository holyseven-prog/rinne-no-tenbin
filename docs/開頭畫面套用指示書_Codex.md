1. **先完整讀過 `assets/design/title/manifest.md`**。座標、九宮格、文字顏色都以它為準。

## 2. 素材打包（單一 HTML）

### 2-1. 要打包的檔案
只打包 runtime 要用的 PNG：
- `title/title_bg_0_scene.png`、`title/title_bg_1_sparkles.png`、`title/title_frame_menu.png`
- `title/title_logo_ja_plain.png`、`title/title_logo_zh_plain.png`（標題畫面用 plain 版）
- `ui/*.png`、`save/*.png`、`settings/*.png`、`mode/*.png`、`god/*.png`、`opening/*.png`

**不打包**：
- `mockup/`、`src/`、`*.svg`
- 含天秤版 Logo（`title_logo_ja.png`、`title_logo_zh.png`，留給 Steam 等其他用途）
- `manifest.md`、`validation.json`

### 2-2. 作法
- 修改 `build.js`：讀取上面的檔案，轉成 base64，產生 `const ASSETS = { 'title/title_bg_0_scene.png': 'data:image/png;base64,...', ... }`，放在其他 script 的**最前面**。
  - **不要**把 base64 寫進 `src/*.js`，原始碼要保持乾淨。
- 新增 `src/11g_assets.js`：
  - `loadAssets()`：把 ASSETS 轉成 `Image` 並等待載入完成。
  - `asset(key)`：取得已載入的圖。
  - 要在 `Screens.boot()` 之前完成載入。
- `test/sim_bundle.js` **不要**包含 ASSETS，模擬測試不需要圖。
- `index.html` 增加的大小應該在 **3.2MB 以內**（素材約 2.3MB，轉成 base64 後約 ×1.34）。

## 3. 顯示規則（全部都要遵守）

| 規則 | 內容 |
| --- | --- |
| 放大倍率 | 所有素材都是 **原寸 ×2** 顯示（640×360 → 1280×720；按鈕 160×32 → 320×64）。**只能用整數 2 倍**，不可以用其他倍率 |
| 例外 | 神格紋章 128／64／32 以 **1:1** 顯示（manifest：紋章以 128×128 顯示） |
| 不可模糊 | CSS 一律 `image-rendering: pixelated`；canvas 一律 `imageSmoothingEnabled = false` |
| 座標 | manifest 的座標都是 1280×720 座標，直接用 |
| 文字 | 由程式顯示，用系統字型、不嵌入字型檔。一般 18～28px，主標 36px；顏色：一般 `#EEF5FF`、選中 `#FFE7A2`、不能按 `#A7AEB8`；黑色陰影偏移 (2,2)。各外框的文字顏色以 manifest 為準 |
| 版權列 | 24,682,1232,24。內容改成 `© 2026 SEVEN`；拿掉目前的「all assets generated by code」 |

### 3-1. 九宮格
- 寫一個共用函式 `nineSlice(key, w, h)`：
  1. 依 manifest 的切割值（上、右、下、左；**以素材原寸為單位**）把素材切成 9 塊。
  2. 四個角不變；四條邊和中央用**最近鄰**拉伸。
  3. 在原寸大小的 canvas 上組好，再整數放大 ×2，輸出成 1280 座標的 w×h。
  4. 用 `key＋w＋h` 快取結果。
- 為了保持整數倍，**w、h 必須是偶數**。
- 對照用的切割值：

| 素材 | 切割值（上、右、下、左） | 內距（原寸） |
| --- | --- | --- |
| `ui_btn_menu_*`、`ui_frame_*`、`title_frame_menu`、`save_slot_*`、`god_card_*`、`mode_card_*` | 14,14,14,14 | 按鈕 8,16,8,16；外框 16,16,16,16 |
| `ui_btn_small_*`、`ui_btn_back_*`、`settings_tab_*` | 13,14,13,14 | 8,16,8,16 |
| `mode_badge_recommended` | 0,14,0,14（**高度固定 24**，只能左右伸縮） | 8,16,8,16 |
| `settings_slider_track` | 2,6,2,6（**高度固定 12**，只能左右伸縮） | — |

- 也可以改用 CSS `border-image`，但要通過 §6 的像素測試：放大後不能有模糊或半格的像素。

### 3-2. 按鈕狀態
- 有 4 種狀態：`normal`（一般）、`hover`（滑鼠移上去，**也是鍵盤目前選到的那一個**）、`press`（按下時）、`disabled`（不能按）。
  - 例：沒有存檔時，「繼續遊戲」用 `disabled`。
- 存檔格、卡片、分頁另外有 `selected`（選中）、`empty`（空格）。
- 鍵盤要能操作：上下（卡片是左右）移動、Enter／Space 決定、Esc 返回。現有的數字鍵 1～3 選神格要保留。

## 4. 各畫面

位置都照 manifest「畫面位置」表；下面只寫額外的規則。

### ① 點擊開始
- 圖層：`title_bg_0_scene` ＋ `title_bg_1_sparkles`。
- 提示文字放在 320,620,640,40，慢慢閃爍。
- 點一下或按任意鍵 → 進入標題。**背景不要換**，直接接到標題，再淡入 Logo 和選單。

### ② 標題
- 圖層順序：
  1. `title_bg_0_scene`（不動）
  2. `title_bg_1_sparkles`：整層 alpha 在 0.35～1 之間來回，週期 2 秒（sin 曲線）。
  3. Logo：依目前語言用 `title_logo_ja_plain` 或 `title_logo_zh_plain`，160,64,960,224，淡入 0.8 秒。
  4. 選單外框：900,368,348,296。
  5. 4 顆按鈕：916,380+72n,320,64。
  6. 版權列。
- **不做視差捲動。**
- 按「語言」時，Logo 和所有文字要**立刻**換成另一種語言。
- 設定裡若有「減少動態效果」選項（沒有的話就在 ④ 新增），開啟時星光固定 alpha 1、Logo 不淡入。

### ③ 讀取存檔
- 背景 `save_bg`；視窗 112,52,1056,616，用 `ui_frame_window` 九宮格。
- 4 格：152+492c,160+220r,464,188（c、r＝0～1）。
- 有存檔：`save_slot_normal`。顯示第幾世、第幾年、季節、神格（左邊放 32px 紋章）、遊玩時間、存檔日期。
  - 存檔資料裡沒有遊玩時間或日期的話，**請新增欄位**；舊存檔顯示「—」。
- 空格：`save_slot_empty`，顯示「空」。
- 目前選到的格子：`selected`。
- 用來「存檔」時（遊戲中），4 格都能選，有存檔的要確認是否覆蓋。用來「讀取」時，空格是 `disabled`。
- 左下角放返回鈕（`ui_btn_back`）。

### ④ 設定
- 背景 `settings_bg`（遊戲中打開時改成半透明暗層）；視窗 180,60,920,600。
- 4 個分頁（`settings_tab_normal`／`selected`）。目前的設定項目分成以下 4 頁：
  - **一般**：語言、文字速度、減少動態效果（新增）
  - **聲音**：BGM 音量、音效音量
  - **遊戲**：預設遊戲速度、自動減速，以及其他和遊戲進行有關的現有項目
  - **畫面**：主題、全螢幕等，以及其他和顯示有關的現有項目
  - 簡單模式開關（V4.1 新增的）放在「遊戲」分頁
- 開關用 `settings_toggle_on`／`off`，ON／OFF 文字由程式顯示。
- 滑桿：軌道 `settings_slider_track`（只能左右伸縮）＋把手 `settings_slider_thumb`。可以拖曳，鍵盤左右可以調整。

### ⑤ 模式選擇（新增）
- 流程：標題「新遊戲」→ **模式選擇** → 神格選擇 → 開場劇情。
- 背景 `mode_bg`；2 張卡 208+480n,130,384,500（左：普通，右：簡單）。

  - 文字沿用 V4.1 現有的 `easy_mode`、`easy_d`；普通模式的說明請新增一條。
