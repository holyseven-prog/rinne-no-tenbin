## 0. 共通規格

| 項目 | 規格 |
| --- | --- |
| 畫布 | 每格 **16×24**（不變；地圖格子 16×16） |
| 比例 | 照設計圖：**大頭的 2 頭身**，頭部（含頭髮、帽子）約佔 12/24 行 |
| 外框 | 深色外框（沿用 `#181020`），照設計圖的粗細 |
| 色數 | 每個角色 ≤ 16 色 |
| 色票 | 以設計圖下方的 16 色為基準（見 §0.1） |
| 方向 | 前、後、左、右。**左＝臉朝左**；右可以用左的鏡像（設計圖的右圖本身就接近鏡像）。要通過 `test/facing.js` |
| 動作 | 設計圖是站姿。走路 4 幀、待機、攻擊、祈禱、受傷，請以站姿為基準延伸，**不可改變服裝與持物** |
| 作法 | 沿用 Sprite DSL（`src/11a_spritedata3.js` 等）。**移除 V3.4「每職業 3 種外觀」的服裝差異** |

### 0.2 「100% 照做」的範圍
- **服裝、帽子、髮型、持物、配色、輪廓**：完全照設計圖的「前」圖。
- **個體差異**：同職業同性別的人，服裝一律相同。為了避免人群裡完全一樣，**只允許改變髮色（3 種）與膚色（3 種）**。
  - 帽子或兜帽蓋住頭髮的職業（魔法師、盜賊、僧侶、防具商人等），就只改膚色。
  - 加一個設定 `NPC_VARIANTS`（預設開）。SEVEN 若要完全一模一樣，關掉即可。
- **武器規則**（設計圖的註記）：
  - 店家 3 職業（商人、武器商人、防具商人）**不拿武器**，揹著商品。
  - 其他職業**都拿武器或工具**。

### 0.3 設計圖中各方向不一致的地方（統一規則：以「前」圖為準）
設計圖有幾處前、後、側面畫得不一樣。實作時**一律以「前」圖的服裝為準**，後面與側面配合前圖：

| 職業 | 不一致 | 處理 |
| --- | --- | --- |
| 商人（男） | 前圖是藍底花紋頭巾，後、側是綠色頭巾 | 全部用**藍底花紋頭巾** |
| 防具商人（女） | 前、側是白色頭巾（紅色花紋帶），後圖是鐵盔 | 全部用**白色頭巾**；後圖的鐵盔是背包上的商品 |
| 武器商人（男女） | 後圖的背包上有紅色怪臉 | 後圖只畫背包和插著的劍、槍、斧，**不畫怪臉** |
| 藥師（男） | 側面的持物不一樣（花束、藥袋） | 以前圖為準：左手花束、腰間藥袋 |
| 鐵匠（女） | 後圖的臉、膚色不一樣 | 後圖照前圖的髮色、膚色畫背面 |

## 2. 設計圖沒有的角色（照同樣畫風補做）

設計圖沒有以下 3 種。請照設計圖的畫風、比例、外框、色票補做；**完成後由 Claude 預審，再請 SEVEN 確認**：

| 角色 | 規格（沿用 A13 的原則） |
| --- | --- |
| 史官 `historian` | 藏青色學者帽（軟帽）、圓眼鏡；藏青長外套金邊；抱著厚書，手持羽毛筆 |
| 小孩（14 歲以下） | 頭更大（約 1.8 頭身）；穿父母職業的簡化版服裝（例：農家孩子戴小草帽）；不拿武器 |
| 老人（56 歲以上） | 白髮或禿頭，男性白鬍；微駝背；拄拐杖；服裝用該職業的灰暗版 |

另外，**勇者候補**（A11：Lv6 以上的劍士）用劍士的造型，頭上加小銀星。**不可**使用勇者的披風與頭冠。

## 3. 驗收

1. **對照圖**：產出 `test/out/visual/npc/compare_<職業>.png`。左邊是設計圖該職業的放大圖，右邊是實作（同一倍率，前、後、左、右 × 男女）。11 職業都要有。
2. **剪影測試**：全職業剪影總覽；只看剪影就能分辨 11 種職業。
3. `test/facing.js` 通過（左右方向正確）。
4. 每個角色 ≤ 16 色。
5. 地圖實機截圖：村莊中 36 人的畫面，各職業一眼可辨（日／中各 1 張）。
6. **Claude 預審**：逐職業比對設計圖，服裝、持物、配色不符就退回。
7. **SEVEN 驗收**：「和設計圖一樣」才算完成。
