## 1. 新方針：直接使用設計圖，用 2 倍解析度顯示

### 1-1. 解析度
- **遊戲邏輯的格子維持 `TS = 16`**。地圖、移動、碰撞都**不改**。
- **只改畫面的畫法**：世界改畫在 **1280×720 的 canvas** 上，每格 = **32×32 螢幕像素**，和設計圖寫的「1 格 32×32px」相同。
  - 目前是畫在 640×360 再放大 2 倍；這次改成直接用 1280×720 畫。
  - 也就是說，素材的細節是目前的 **2 倍**。
- 素材大小（螢幕像素）：

| 種類 | 大小 |
| --- | --- |
| 地面 tile | 32×32 |
| 人物（NPC、冒險者） | **32×48**（佔地和現在一樣是 1×1.5 格，但細節變 2 倍） |
| 建築 | 寬＝設計圖格數 × 32（例：旅館 7 格＝224px）；高依設計圖的比例（屋頂可以超出佔地往上長） |
| 小物件 | 32×32（大一點的可以 32×48 或 64×32，照設計圖比例） |
| 敵人 | 照設計圖的尺寸表：小型 32×32、中型 32～48、大型 48～64、巨龍 96、幹部 64×96、魔王 96 |

- 背景、地面、建築、人物、敵人**全部用同一個 32px 格**，不可以混用不同的像素密度。

### 1-2. 素材來源：從設計圖擷取，不要自己重畫
- 敵人那次的作法（`tools/enemy_extract.js`）是對的，**所有素材都用同樣的方式**：
  1. 從 SEVEN 的設計圖裁切出每個素材（建築逐棟、物件逐個、tile 逐種、NPC 逐職業逐方向）。
     - 設計圖在 `docs/figures/{npc,village,field,enemy}/`。
  2. 去掉背景（米色底、格線、標籤文字），做成透明背景。
  3. 縮放到 §1-1 的目標尺寸。
     - 用**面積平均（area）縮小**，再做**調色盤量化（每個素材 ≤ 32 色）**，並清掉半透明的邊。
     - **不可以用最近鄰直接縮**，會破碎。
  4. 外框補成 1px 深色（`#181020` 系），讓素材在地圖上清楚。
- **不可以自己重新設計或簡化**：形狀、配置、裝飾、顏色都要保留設計圖原本的樣子。
- 擷取工具放在 `tools/`，裁切座標存成 JSON。之後設計圖更新時，可以重新產生。

### 1-5. 擷取的效果範例（Claude 試做）
左邊是從設計圖直接擷取、縮小成高 48px 的版本（放大 4 倍顯示），右邊是設計圖原圖。設計的形狀、臉、裝飾都保留下來了，**NPC 要達到這個程度**。
- 正面那兩張的白底沒有去乾淨，是試做時裁切框框到了表格邊線。正式版要去乾淨。
- 拿劍等持物的姿勢，寬度可以超過 32px（例：35×48）。對齊方式：腳底置中。

### 1-3. 各類細則
- **建築**：
  - 照設計圖的**正面朝向外觀**。門的位置要對準地圖上的門口格（`DOOR`）。
  - 建築下半部（佔地）不能走；屋頂往上超出的部分，人物走到後面時要被遮住（照目前的 Y 排序）。
- **NPC**：
  - 4 方向照設計圖。走路動作用設計圖的站姿做 2～4 幀（只動腳和手），**頭和身體照原圖**。
  - 個體差異只能換髮色和膚色（同 Part A）。
- **地面 tile**：
  - 從設計圖擷取 32×32，做成可以無縫拼接的版本。
  - 草地要有 5 階明暗變化，四季版本照設計圖。
- **敵人**：
  - 地圖和戰鬥畫面**都用同一張圖**（不要再另外做 16×16 的縮小版）。
  - 魔狼的空白幀、巨龍和魔王旁邊的線（預審必修 3、4）一起修正。
- **魔王城內、野外**（Part C、D）：還沒做的部分，之後也照這個方式做。

### 1-4. 效能
- 1280×720 的 canvas，60fps。
- 建築和地面請先畫到**離屏 canvas** 快取，不要每幀重畫。
