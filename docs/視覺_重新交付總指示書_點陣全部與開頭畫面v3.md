# 第一部　遊戲世界的點陣素材（NPC、魔物、城鎮、野外、魔王城內）

## 1-0. 為什麼要重新交付

Codex 照《視覺總指示書》把 4 張素材圖逐像素轉進遊戲時，發現素材圖（各 1536×1024）**不是乾淨的點陣圖**：

| 問題 | 實測 |
| --- | --- |
| 1 個「點」由 2～3 個像素組成，邊緣是模糊的漸層 | NPC 每個角色有 **2,500～6,600 色**（中位數約 3,800 色）。點陣圖應該只有 16～32 色 |
| 點和點沒有對齊同一個像素格 | 不能用整數倍乾淨放大 |
| 同一類素材的比例不一致 | 角色約 50×95px、建築 1 格約 16px、地面樣本 1 格約 70px |

目前遊戲**暫時**用「每個像素原樣保存（無損壓縮）」的方式（方案 A），畫面和素材圖一模一樣，但模糊也一起保留，容量也很大。
**請把 4 張素材圖做成「乾淨的點陣版本」。** 交來之後 Codex 直接替換，程式不用改。

---

## 1-1. 原則（違反就不合格）
1. **設計不變**：造型、比例、配色、持物、表情、裝飾，和素材圖一樣。SEVEN 看了要說「這就是我的圖」。
2. **只做「點陣化」**：
   - 1 個點 = 1 個像素，對齊像素格。
   - 拿掉模糊、漸層邊、雜訊、抗鋸齒、JPEG 色塊。
   - 相近的顏色合併成乾淨的色階（例：一塊布料 3～4 階：亮、中、暗、陰影）。
3. **不可以**：
   - 改造型、改配色方向、改比例；
   - 新增素材圖沒有的裝飾、拿掉素材圖有的東西；
   - 加外框（素材圖本身的深色輪廓要保留）；
   - 自行設計素材圖上沒有的素材（例外見 §1-6，而且必須交給 SEVEN 確認）。

---

## 1-2. 作業方法（照這個流程，才能做到 100%）

### 步驟 1：裁切
- 從素材圖**原圖**（`docs/figures/<類別>/*_design_sheet.png`，1536×1024）裁出每一個素材。
- **不可以用** `figures/` 裡其他放大過的預覽圖。
- 裁切時不要包含格線、標籤文字（「前」「後」「7×5」等）。

### 步驟 2：做底稿
- 把裁出來的圖**縮放到 §1-3 的原生尺寸**（例：人物縮到高 48px），放在繪圖軟體最下層，不透明度 50%。
- 另外開一層「放大 4 倍的原圖」放在旁邊參考細節。

### 步驟 3：逐點描繪
- 在原生尺寸的畫布上，**一點一點**照底稿描。
- 每一點的顏色，從原圖對應位置**吸色**，再歸到該部位的色階裡。
- 輪廓（最外圈深色線）照原圖保留，**不加粗、不變細、不新增**。
- 小細節（眼睛、徽章、扣子、窗戶）要保留；縮小後放不下的，用 1 個點表現，不可以省略。

### 步驟 4：自我檢查
- 把成品**最近鄰放大到原圖大小**，和原圖並排、疊圖（50%）比對：
  - 輪廓、各部位的位置要對齊（誤差 ≤ 1 點）；
  - 顏色方向一致（例：勇者是藍頭髮、紅披風、藍盔甲）；
  - 沒有多、沒有少。
- 產生對照圖（§1-8）。

## 1-3. 共通規格

| 項目 | 規格 |
| --- | --- |
| 格式 | PNG（RGBA），透明背景 |
| 透明 | alpha 只能 0 或 255；**不可以有半透明的邊** |
| 1 點 | = 1 像素（不放大交付） |
| 色數 | 每個素材**目標 ≤ 32 色**，最多 256 色；同一類（例：全部人物）盡量共用一組調色盤，附 `palette_<類別>.png` |
| 邊緣 | 最外圈是素材圖原本的深色輪廓；**不可以有白邊、淺色毛邊** |
| 方向 | 左、右**各自交**（照素材圖，不可以用鏡像代替）。素材圖只有一個側面的，才可以用鏡像，並在 manifest 註明 |

## 2-1. 作業方法（為了做到 100%，一定要照這個流程）

### 2-1-1. 先做「底稿」
1. 從提案圖裁出每個畫面的縮圖（例：② 標題畫面那一格）。
2. 把縮圖**放大到 1280×720**（雙線性放大即可，這只是描圖用的底稿）。
3. 在繪圖軟體裡，把底稿放在最下層、不透明度 30～50%，**在上面描繪**。
4. **主要物件的位置、大小、輪廓要對齊底稿**：
   - 允許誤差：位置 ±16px、大小 ±5%（以 1280×720 計）。
   - 例：② 的 Logo、魔王城、村莊、橋、選單框，都要落在底稿的同一個位置。
5. 交付時把底稿也一起交（`ref/<檔名>_ref.png`），Claude 驗收時會疊圖比對。

### 2-1-2. 顏色
- 從提案圖對應位置**吸色**作為基準色（天空、城、金框、羊皮紙……）。
- 可以加中間色讓高解析度更細緻，但**整體色相、明暗、彩度要和提案圖一致**。
- 每張附上 `<檔名>_palette.png`（主要顏色色票），標示「取自提案圖的哪個位置」。

### 2-1-3. 細節補畫的規則
- 提案圖縮圖太小看不清楚的地方（窗戶、樹葉、裝飾紋樣），**照同一張提案圖其他地方的畫法補**。
- 不可以新增提案圖上沒有的主要物件（例：多一座塔、多一個人物、換成別的動物）。
- 不可以拿掉提案圖上有的物件。

### 2-1-4. 逐張對照圖（交付必備）
- 每一張交付品都附 `compare/<檔名>_compare.png`：**左：提案圖該格（放大到同尺寸）｜右：交付品**，2560×720。
- 另附 `compare/<檔名>_overlay.png`：交付品上面疊 50% 的提案圖底稿，用來確認位置對齊。

## 2-7. 驗收

### 2-7-1. Codex 自動檢查（`test/title_v3_check.js`）
1. 每個檔案的尺寸、格式、alpha（0／255，Logo 與文字圖片除外）、色數符合 §2-2。

4. 背景 1280×720，沒有「2×2 同色區塊」（確認不是 640×360 放大）。
5. 容量合計 ≤ 8MB。

- 拿 `compare/` 與 `ref/` 疊圖，逐張檢查：

  - 配色方向一致；
  - Logo 的字型風格（金色、立體、描邊）一致。
- 不合格的項目，逐條列出退回。
